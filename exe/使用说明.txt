时间规划 TimePlanner 1.7 特别版
==============================

主程序      : TimePlanner.exe        规划今日与本周计划
桌面插件    : TimePlanner.Widget.exe 摆在桌面上显示任务、勾选完成
启动脚本    : 启动时间规划.cmd

快速上手
--------
1. 双击 TimePlanner.exe（会同时启动桌面插件）。
2. 点任务左侧圆圈 = 完成（会放一筒小礼花，左下角的小人还会说一句贺辞）；底部输入框回车 = 新增任务。
3. 输入时可加标记：结尾 !! = 紧急，! = 重要，#标签 = 分类，例如：
     提交季度报告 !! #工作
4. 插件：拖动标题栏移动，双击标题栏打开主程序，右键可切换层级/隐藏/退出；
   右键菜单是木色皮肤，每项都带图标，并用主题色和右侧小圆点标出当前层级与日期状态。
   「今日事明日毕」：把这天没办完的事整体挪到第二天（主程序今日页也有同一个按钮）。
5. 插件左下角那位小人：他平时挂着「臣在此候旨」，你办成一件事，他就弹对话框回一句，
   过一会儿自己收回去；点他一下他也有话说。主程序侧栏左下角也是他，常驻报一句今日进展。
6. 插件缩放：鼠标移到插件边缘或右下角变成缩放指针后按住拖动即可自由缩放，宽度
   和高度分开记忆；右键菜单或主程序设置页里的「恢复自适应大小」可还原。
7. 任务改期：在「本周」页按住任务行拖动，拖到顶部一周概览的日期格或某天卡片上松手，
   任务就改到那一天（拖动时目标会高亮）。任务多到一屏放不下时，把鼠标拖到列表的
   上边缘或下边缘停一下，列表会自己往上/往下翻，不用松手再滚。
8. 插件全屏适配：你开全屏游戏/全屏演示时插件会自动收起，退出全屏后自动恢复，
   不会和全屏画面抢渲染而掉帧；不需要的话可在主程序设置页关掉。
9. 主程序点右上角 ✕ 只是隐藏到托盘；托盘右键可退出。

数据位置
--------
%APPDATA%\TimePlanner\data.json
（主程序与插件共用；删除该文件即可重置为初始状态）

卡住/异常了怎么查
---------------
日志文件：%APPDATA%\TimePlanner\timeplanner.log
（界面被卡住超过 1.2 秒、全屏隐藏恢复、未捕获的异常都会记录在这里，
  超过 256 KB 会自动清空重记）

本版更新（1.7）
---------------
* 插件顶上的周条重做了：一格两行——上面周几、下面日期数字（14 / 15 / …），今天描红加框、
  选中的那天填朱砂；格子底下的小圆点还是那天的完成进度（绿 = 全部办完）。鼠标停在格子上
  会显示「9月18日 周五 · 已竟 1 / 2 事」。
* 主程序也有小人了：常驻侧栏左下角，头顶一个对话框跟着今日进展报数（「尚余 3 事，臣这就办」
  「诸事办妥，臣复命」「今日无事，臣候旨」），每次刷新这句话变了就弹一下；点他一下
  换一句随机贺辞，7 秒后回到进展那句。插件里那位也能点。
* 小人的话一律改成臣子口吻，贺辞扩到 34 句、全是恭喜圣上的话（「臣恭喜圣上，又了却一桩」
  「贺喜圣上，此事已成」「臣恭贺圣上，心愿又了」…），落款「—— 臣 恭 贺」，
  待命那句「臣在此候旨」，侧栏报数也是「尚余 3 事，臣这就办」。
* 侧栏的「今日进度」卡片和「显示/隐藏桌面插件」按钮挪到侧栏最下面，给小人腾出位置。
* 新增「今日事明日毕」：插件右键菜单和主程序今日页各一个，一键把这天没办完的事整体
  挪到第二天，插件点完会跟着跳到第二天看看落哪儿了。
* 修好插件右键「打开主程序」按了没反应：主程序缩在托盘里时窗口是隐藏的，按窗口句柄
  找不到人、重新启动又会被单实例挡住。现在改成用一盏命名事件信号灯叫它显形，
  可见/隐藏两种状态下都能打开。

上一版（1.6）
---------------
* 整套界面换成「经典古代圣旨」的样子：木牍 + 明黄绢面 + 朱砂金线，标题用华文新魏/隶书、
  正文用楷体。主程序上下各一根鎏金卷轴轴杆，侧栏小标题「奉天承运」，四个页面改叫
  「今日圣旨 / 本周奏章 / 已竟之事 / 钦此设置」，页眉右侧盖一枚「御览」朱印。
* 插件同样换成卷轴 + 织锦外框 + 绢面，抬头写「今 日 事 宜」。
* 插件左下角多了一位小人物（清朝小皇帝正面半身卡通，透明底 PNG 直接打在 exe 里，
  不用外带图片文件）。他独占页脚最后一行，压不到任何文字。
* 完成任务的鼓励语改成小人的对话框：宣纸底 + 金褐描边 + 朱砂字，落款「—— 臣 恭 贺」，
  一堆恭贺话随机（「臣恭喜圣上，又了却一桩」这类，1.7 起扩到 34 句）；当天的事情全部
  办完时他说「诸事皆了，臣恭贺圣上」。对话框弹一下就收，9 秒后回到待命的「臣在此候旨」。
* 右键菜单跟着换成木色皮肤（木牍底 + 鎏金描边）。
* 插件缩放下限改成「页眉、周条、进度、页脚、小人都看得见，外加一小块列表」，
  缩到最小也不会把小人或输入框压没。

上一版（1.5）
---------------
* 占用更小了：空闲时两个进程的工作集都会降回 1 MB 上下（之前是 30~40 MB）；
  桌面插件改走软件渲染，少加载了显卡那一套（省下约 20 MB）。任务管理器里看到的
  数字就是它，收起主界面后最明显。
* 拖动任务现在能滚动了：按住任务拖到列表的上/下边缘并停一下，列表会自动往上/下翻页，
  越靠边翻得越快，拖到自己看不见的日期也不用松手重来。（顺带修掉了一个老毛病：
  以前贴到边缘只滚一下就当「已经到头」停住了。）
* 拖动改期、勾选完成之后，页面不会再跳回顶部：刷新前会记住滚动位置，而且每个页面
  各记各的，切来切去也还在原处。
* 插件放着不管时会隔十几秒把内存还给系统，勾选、缩放、放礼花的时候都不会回收，
  不会因此发涩。

上一版（1.4）
---------------
* 完成任务的礼花筒做得更到位了：勾选框处会举起一个斜着的小纸筒，一束彩纸
  （圆点、方片、波浪彩带）扇形喷出去，边翻转边抛上去再落下来；
  旁边同时飘出一句鼓励的话（「干得漂亮！」这类，10 句随机）。
* 当天任务全部完成时，会在内容区中央再补一筒更大的礼花。
* 彩纸的喷射范围会跟着窗口大小自动调整，桌面插件面板窄也不会飞出面板被裁掉。

注意事项
--------
* 两个 exe 请放在同一个文件夹里，插件由主程序按同目录查找并启动。
* 需要 .NET Framework 4.8（Windows 10/11 已自带），无需安装其他运行库。
* 「贴在桌面」模式下插件位于所有窗口最下层，点击会自动浮到最前。
