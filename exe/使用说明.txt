时间规划 TimePlanner sp2 特别版
==============================

主程序      : TimePlanner.exe        规划今日与本周计划
桌面插件    : TimePlanner.Widget.exe 摆在桌面上显示任务、勾选完成
启动脚本    : 启动时间规划.cmd

快速上手
--------
1. 双击 TimePlanner.exe（会同时启动桌面插件）。
2. 点任务左侧圆圈 = 完成（会放一筒小礼花，左下角的小人还会说一句贺辞）；底部输入框回车 = 新增任务。
3. 输入时可加标记：结尾 !! = 紧急，! = 重要，#标签 = 分类，例如：
     提交季度报告 !! #工作
4. 插件：拖动标题栏移动，双击标题栏打开主程序，右键可切换层级/隐藏/退出；
   右键菜单是木色皮肤，每项都带图标，并用主题色和右侧小圆点标出当前层级与日期状态。
   「今日事明日毕」：把这天没办完的事整体挪到第二天（主程序今日页也有同一个按钮）。
5. 插件左下角那位小人：他平时挂着「臣在此候旨」，你办成一件事，他就弹对话框回一句，
   过一会儿自己收回去；点他一下他也有话说。主程序侧栏左下角也是他，常驻报一句今日进展。
6. 插件缩放：鼠标移到插件边缘或右下角变成缩放指针后按住拖动即可自由缩放，宽度
   和高度分开记忆；右键菜单或主程序设置页里的「恢复自适应大小」可还原。
7. 任务改期：在「本周」页按住任务行拖动，拖到顶部一周概览的日期格或某天卡片上松手，
   任务就改到那一天（拖动时目标会高亮）。任务多到一屏放不下时，把鼠标拖到列表的
   上边缘或下边缘停一下，列表会自己往上/往下翻，不用松手再滚。
8. 插件全屏适配：你开全屏游戏/全屏演示时插件会自动收起，退出全屏后自动恢复，
   不会和全屏画面抢渲染而掉帧；不需要的话可在主程序设置页关掉。
9. 计划可以再分一层：侧栏「项目档案」页里先立大项目（比如「毕业设计」），再往里加小项目，
   或者用「分段」把项目分期（「开题阶段」→「定稿阶段」）。最低一级的「小项目」本身就是一条
   任务 —— 今日、本周、桌面上都能看到它、勾它、拖它改期，和普通任务排在同一列，行上多一枚
   归属小标签（毕业设计 / 开题阶段）；大项目和分段那行会显示「已竟 x / y」的进度。
10. 主程序点右上角 ✕ 只是隐藏到托盘；托盘右键可退出。

数据位置
--------
%APPDATA%\TimePlanner\data.json
（主程序与插件共用；删除该文件即可重置为初始状态）
data.json.bak   上一份自动备份，主文件写坏时下次启动会自动从它恢复
data.json.corrupt-*  主文件读不出来时留下的现场（可以发给我看）
所有版本（1.5 / 1.6 / 1.7 / sp1 …）共用这一份数据，来回换版本不会互相覆盖。
sp1 起数据里多了 projects（项目树）和任务上的 projectId：旧版本读它没问题（不认识的字段会跳过），
但旧版本保存时会把项目丢掉 —— 所以用 sp1（原 1.8）建了项目之后，别再用更早的版本改数据。

更新日志
--------
CHANGELOG.md（就在这个目录里）：两条产品线（特别版 / 经典版）的改动都只记这一个文件，
标 [内核] 的条目是两条线通用的 —— 经典版照着同步就能跟上（sync-classic.ps1）。
两条线各自一个版本序列，标签也分开：特别版 special/v1.6、special/v1.7、special/sp1、…；经典版 classic/v1.5、…。
下载包同理：特别版叫 TimePlanner-<版本>-special，经典版叫 TimePlanner-<版本>-classic。

版本隔离
--------
同一台机器上可以同时装、同时开多个版本：
* 单实例、进程间信号灯、桌面插件、开机自启条目都按「版本 + 安装目录」各算各的，
  两个版本互相不挡，插件也各管各的（A 版的插件不会去杀 B 版的插件）。
* 数据仍然共用一份 %APPDATA%\TimePlanner\data.json，换版本不会丢。
* 同一个目录重复点 = 还是只开一个：会把已经开着的那个窗口叫到前面来。
* 设置页「开机自动启动」下面会提示还有哪些版本也注册了自启，方便你决定留哪个。

卡住/异常了怎么查
---------------
日志文件：%APPDATA%\TimePlanner\timeplanner.log
（界面被卡住超过 1.2 秒、全屏隐藏恢复、未捕获的异常都会记录在这里，
  超过 256 KB 会自动清空重记）

本版更新（sp2）
---------------
* 主程序左下角多了一个「保存计划」按钮：计划本来就每次改动自动落盘，这个按钮是「现在就写」的手动
  兜底 —— 点一下立刻写进本地文件（鼠标停在按钮上写着路径），按钮下面回一句「已保存到本地 · 时刻」。
* 修好「输入完一回车，页面跳回顶部」：今日 / 本周 / 项目档案 / 已完成 / 设置五个页面都改成重画时
  只换里面的内容、滚动区留着接着用，打完字回车、勾完一项都不会再跳回顶上。
* exe 有了固定位置：特别版的 exe 现在放在时间规划-special 那个文件夹里（跟经典版的
  TimePlanner-1.5-classic 并排），不用再去按日期开的工作目录里翻。

上一版（sp1）
---------------
* 项目档案更好用：大项目 / 分段那一行上直接分份 —— 用 ⊖ n ⊕ 分成几份（0 = 不分份），
  再拖横条记「几份之几」，拖到最后一格就是整段办完；不用再一条条写小项目了
  （小项目本身就是一条事项，不分份）。点 ⊕ / ⊖ 只改份数，不会顺手把这一行收起来。
* 项目 / 分段行最前面那枚「完成」圆勾，就是任务行上那枚勾选框（同一个控件）：点一下整段办完
  （底下的小项目全部勾上、份数置满、名字跟任务标题一样划掉），再点一下整段撤销，
  做完照样放一筒礼花 + 一句鼓励语；底下还什么都没有的空项目 / 空分段，点一下也会记成「办完了」，
  不会是点了没反应的按钮。
* 插件上也能直接办「几分之几」：分了份的大项目 / 分段在桌面插件列表里各占一行（上下的层级用缩进表示），
  行上只写「x/n」；点那枚勾只办完 1 份（不再是一按就整段办完），办满最后一份才放礼花、
  小人才接一句贺词。办满之后整行会跟办完的任务一样收起来（点「已竟之事」才看得见），
  再点一下 = 撤销重来。没分份的项目按小项目算，插件上就是那条普通事项，不会多出一行。
* 压在旧日期里的未竟之事不再隐形：今天要是空着、而前面几天还有没办完的，主程序今日页顶部
  和插件列表顶上都会写一句「此前尚余 N 事未竟」，旁边一个「全部挪到今天」（插件右键菜单
  里是「过期未竟挪到今天」），按一下就把这些旧账整体顺延过来。
  （以前它们只是静静留在旧日期里，打开今日页空空如也，很容易误会成数据丢了。）
* 数据写盘更稳：每次覆盖 data.json 前先把上一份留成 data.json.bak；主文件要是被写坏、
  被杀毒软件半路截断，下次启动会自动从 .bak 恢复，并把坏掉的那份存成 data.json.corrupt-时间戳。
* 修好「桌面插件能开出两个来」：单实例用的互斥体原先只是个局部变量，Release 下会被 GC
  提前收掉、闸门就悄悄失效了。现在挂到静态字段上，点第二次只会把已经在跑的那个插件
  叫到前面来（以前是静默退出，看着像没反应），不会再叠一个新的跟你抢同一份文件。
* 版本隔离：单实例、信号灯、桌面插件、开机自启条目都按「版别 + 安装目录」算，
  两个版本（比如特别版和经典版）可以同时装着、同时开着，互不打扰；数据仍然共用一份。
  同一个目录重复点还是只开一个；关插件也只关自己这份目录里的。
* 新增「项目档案」（侧栏第三项）：大项目 → 分段 / 小项目三层。大项目是顶层容器，
  往里加小项目，或者用「分段」把项目分期（开题阶段 / 定稿阶段…），分段里再放小项目。
  * 最低一级的小项目本身就是一条任务：它跟普通任务一起出现在今日、本周和桌面插件里，
    能勾（勾了照放礼花）、能按住拖到别的日期、能顺延，行上只多一枚归属小标签。
  * 大项目和分段那行显示「已竟 x / y」的进度（按下面的小项目算），行内可以加小项目、
    加分段、改名、上下挪、删除（点一下直接删，连下面的小项目和它们的事项一起删）。
  * 侧栏「项目档案」的角标是还没办完的小项目数。

上一版（1.7）
---------------
* 插件顶上的周条重做了：一格两行——上面周几、下面日期数字（14 / 15 / …），今天描红加框、
  选中的那天填朱砂；格子底下的小圆点还是那天的完成进度（绿 = 全部办完）。鼠标停在格子上
  会显示「9月18日 周五 · 已竟 1 / 2 事」。
* 主程序也有小人了：常驻侧栏左下角，头顶一个对话框跟着今日进展报数（「尚余 3 事，臣这就办」
  「诸事办妥，臣复命」「今日无事，臣候旨」），每次刷新这句话变了就弹一下；点他一下
  换一句随机贺辞，7 秒后回到进展那句。插件里那位也能点。
* 小人的话一律改成臣子口吻，贺辞扩到 34 句、全是恭喜圣上的话（「臣恭喜圣上，又了却一桩」
  「贺喜圣上，此事已成」「臣恭贺圣上，心愿又了」…），落款「—— 臣 恭 贺」，
  待命那句「臣在此候旨」，侧栏报数也是「尚余 3 事，臣这就办」。
* 侧栏的「今日进度」卡片和「显示/隐藏桌面插件」按钮挪到侧栏最下面，给小人腾出位置。
* 新增「今日事明日毕」：插件右键菜单和主程序今日页各一个，一键把这天没办完的事整体
  挪到第二天，插件点完会跟着跳到第二天看看落哪儿了。
* 修好插件右键「打开主程序」按了没反应：主程序缩在托盘里时窗口是隐藏的，按窗口句柄
  找不到人、重新启动又会被单实例挡住。现在改成用一盏命名事件信号灯叫它显形，
  可见/隐藏两种状态下都能打开。

上一版（1.6）
---------------
* 整套界面换成「经典古代圣旨」的样子：木牍 + 明黄绢面 + 朱砂金线，标题用华文新魏/隶书、
  正文用楷体。主程序上下各一根鎏金卷轴轴杆，侧栏小标题「奉天承运」，四个页面改叫
  「今日圣旨 / 本周奏章 / 已竟之事 / 钦此设置」，页眉右侧盖一枚「御览」朱印。
* 插件同样换成卷轴 + 织锦外框 + 绢面，抬头写「今 日 事 宜」。
* 插件左下角多了一位小人物（清朝小皇帝正面半身卡通，透明底 PNG 直接打在 exe 里，
  不用外带图片文件）。他独占页脚最后一行，压不到任何文字。
* 完成任务的鼓励语改成小人的对话框：宣纸底 + 金褐描边 + 朱砂字，落款「—— 臣 恭 贺」，
  一堆恭贺话随机（「臣恭喜圣上，又了却一桩」这类，1.7 起扩到 34 句）；当天的事情全部
  办完时他说「诸事皆了，臣恭贺圣上」。对话框弹一下就收，9 秒后回到待命的「臣在此候旨」。
* 右键菜单跟着换成木色皮肤（木牍底 + 鎏金描边）。
* 插件缩放下限改成「页眉、周条、进度、页脚、小人都看得见，外加一小块列表」，
  缩到最小也不会把小人或输入框压没。

上一版（1.5）
---------------
* 占用更小了：空闲时两个进程的工作集都会降回 1 MB 上下（之前是 30~40 MB）；
  桌面插件改走软件渲染，少加载了显卡那一套（省下约 20 MB）。任务管理器里看到的
  数字就是它，收起主界面后最明显。
* 拖动任务现在能滚动了：按住任务拖到列表的上/下边缘并停一下，列表会自动往上/下翻页，
  越靠边翻得越快，拖到自己看不见的日期也不用松手重来。（顺带修掉了一个老毛病：
  以前贴到边缘只滚一下就当「已经到头」停住了。）
* 拖动改期、勾选完成之后，页面不会再跳回顶部：刷新前会记住滚动位置，而且每个页面
  各记各的，切来切去也还在原处。
* 插件放着不管时会隔十几秒把内存还给系统，勾选、缩放、放礼花的时候都不会回收，
  不会因此发涩。

上一版（1.4）
---------------
* 完成任务的礼花筒做得更到位了：勾选框处会举起一个斜着的小纸筒，一束彩纸
  （圆点、方片、波浪彩带）扇形喷出去，边翻转边抛上去再落下来；
  旁边同时飘出一句鼓励的话（「干得漂亮！」这类，10 句随机）。
* 当天任务全部完成时，会在内容区中央再补一筒更大的礼花。
* 彩纸的喷射范围会跟着窗口大小自动调整，桌面插件面板窄也不会飞出面板被裁掉。

注意事项
--------
* 两个 exe 请放在同一个文件夹里，插件由主程序按同目录查找并启动。
* 需要 .NET Framework 4.8（Windows 10/11 已自带），无需安装其他运行库。
* 「贴在桌面」模式下插件位于所有窗口最下层，点击会自动浮到最前。
