时间规划 TimePlanner 1.5.4（经典版 / 无圣旨皮肤）
================================================

这是 1.6「圣旨特别版」之前的那一版界面：深色主题，没有卷轴木牍、没有小人。
源码在仓库的 classic 分支（version.txt = 1.5.4），这两份 exe 就是由那棵树编译出来的。

主程序      : TimePlanner.exe        规划今日与本周计划
桌面插件    : TimePlanner.Widget.exe 摆在桌面上显示任务、勾选完成
启动脚本    : 启动时间规划.cmd

注意
----
* 两个 exe 请放在同一个文件夹里，插件由主程序按同目录查找并启动。
* 需要 .NET Framework 4.8（Windows 10/11 已自带）。
* 数据和特别版共用 %APPDATA%\TimePlanner\data.json，格式完全一样，
  两边可以轮流开，任务不会丢；但同时只能开一个（单实例互斥）。
* 经典版就是 1.5 那套深色卡片：没有圣旨皮肤、没有小人；
  「今日 / 本周 / 项目档案 / 已完成 / 设置 / 云端共用」这些功能跟特别版是同一套。
