# 免编译包 · 经典版（深色卡片）

这个目录是**经典版 1.5.4 的免编译包**，跟着经典版那条线一起发（源码就在同一个分支里，`TimePlanner/version.txt = 1.5.4`）。
下载下来就能用，不用装 SDK、也不用编译。

| 文件 | 作用 |
| --- | --- |
| `TimePlanner.exe` | 主程序：规划今日与本周，平时缩在托盘里 |
| `TimePlanner.Widget.exe` | 桌面挂件：摆在桌面上显示任务、勾选完成 |
| `启动时间规划.cmd` | 双击启动（等同双击主程序） |
| `使用说明.txt` | 上手说明与版本更新记录 |

## 两点注意

- 两个 exe **必须放在同一个文件夹里**，挂件由主程序按同目录查找并启动。
- 需要 .NET Framework 4.8，Windows 10 / 11 已经自带，不用另外装。

数据放在 `%APPDATA%\TimePlanner\data.json`，跟特别版共用同一份；删掉它就是完全重置。
经典版就是 1.5 那套深色卡片界面：没有圣旨皮肤、没有小人。
