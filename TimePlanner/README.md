# 时间规划 TimePlanner · Windows 桌面时间规划与管理工具

一个原生 Windows 小工具，由**主程序**和**桌面插件**两部分组成：

- **主程序 `TimePlanner.exe`**：规划今日与本周计划（新增/编辑/删除、优先级、标签、完成统计、顺延、清理、设置、系统托盘）。
- **桌面插件 `TimePlanner.Widget.exe`**：摆在桌面上的任务面板，显示已完成/未完成任务，可直接勾选完成、切换查看本周任意一天、快速添加任务。

两个进程共用同一份数据文件，任意一端修改都会**实时双向同步**。

---

## 快速开始

1. 双击 `TimePlanner.exe`（或 `启动时间规划.cmd`）。
2. 主窗口打开的同时，桌面右下角会出现任务面板（默认为「贴在桌面」模式，不遮挡其他窗口）。
3. 点任务左侧的圆圈即可勾选完成（会有一小簇烟火动画），主程序与插件会立即同步。
4. 主程序点 `✕` 会隐藏到托盘，右键托盘图标可重新打开、显示/隐藏插件或退出。

> 两个 exe 必须放在同一目录（主程序按同目录路径启动插件）。

## 桌面插件

**三种窗口层级**（设置页或插件右键菜单可切换）：

| 模式 | 行为 |
| --- | --- |
| 贴在桌面（默认） | 始终位于所有窗口最下层（壁纸之上、其他窗口之下），不遮挡工作；点击它自动浮到最前并获取输入焦点，点击别处又回到最底层 |
| 始终置顶 | 永远显示在最前面 |
| 普通窗口 | 和其他窗口一样参与前后排序 |

**交互**：

- 拖动插件标题栏移动位置，位置自动记忆（下次启动仍在原处）。
- 把鼠标移到插件边缘或右下角，指针变成缩放样式后按住拖动即可自由缩放：宽度和高度分别记忆；右键菜单或设置页「恢复自适应大小」可回到跟随内容自适应。
- 双击标题栏打开主程序。
- 顶部 `◀ 日历 ▶` 切换日期，点周条（每格：周几 + 日期，今天描红）可跳到本周任意一天；格子底下的小圆点是那天的完成进度。
- 底部输入框回车即可添加任务。
- 任务可拖动改期：在「本周」页按住任意任务行，拖到顶部一周概览里的日期格或某天的分组卡片上松手，任务就改到那一天（拖动时目标会高亮）。
- 拖到自己看不见的日期也不用放松手：拖拽光标贴住列表的上/下边缘并停一下，列表会自动往上/下翻页，越靠边越快（详见「流畅度」里的 DragScroller）。
- 右键菜单（木色圆角皮肤、每项带图标，并标出当前所处的层级与日期状态）：打开主程序 / 编辑今天 / 切换层级（贴在桌面 · 始终置顶 · 普通窗口）/ 只显示今天 / 今日事明日毕 / 恢复自适应大小 / 刷新 / 隐藏插件 / 退出插件。
- 完成任务的小烟火：每次勾选完成，勾选框处会放出一筒礼花，左下角的小人同时弹出对话框说一句贺辞；当天任务全部完成时会再补一筒更大的。全程只做位移/缩放/淡出，不用阴影模糊特效，动画放完自动清理，不会常驻占用 CPU。
- 标题栏 `✕` 只隐藏插件，可在主程序托盘菜单里重新显示。
- 全屏适配：检测到独占全屏的程序（游戏、演示、全屏视频）时插件自动收起，退出全屏后自动恢复，避免和全屏画面抢渲染导致掉帧；可在设置页关掉。
- 插件不会出现在任务栏和 Alt+Tab 中。

## 界面细节（1.3 起）

- **右键菜单**：整套菜单是自绘的皮肤（12 px 圆角、描边、柔和投影、悬停高亮），不再用系统那套浅色 Aero 菜单；1.6 起配色从深蓝改成圣旨版的木牍色。
  - 每项都有图标；分隔线按交互分组（打开 / 层级 / 日期与尺寸 / 收尾）。
  - 「当前状态」用主题色文字 + 右侧小圆点标出，一眼能看出插件现在是「贴在桌面 / 始终置顶 / 普通窗口」还是「只显示今天」。
  - 状态标记在菜单弹出时同步，且只改颜色和圆点透明度、不改字号字重，菜单不会在弹出后再变宽。
- **完成任务的礼花筒（1.4 起）**：勾选完成时，勾选框位置会举起一个斜着的小纸筒，一束彩纸（圆点 + 方片 + 波浪彩带，约 28~40 片）扇形喷出，边翻转边被抛上去、再落下来；同时飘出一句贺辞（1.6 起改由左下角的小人用对话框说，见上一节）。当天任务全部完成时，还会在内容区中央再补一筒更大的。
  - 喷射半径按窗口大小自适应：桌面插件面板窄，彩纸会被自动收住，不会飞出面板被裁掉；喷射方向也会朝窗口内侧偏。
  - 一次约 1.4~1.6 秒，放完立刻摘除，不留常驻元素。
  - 粒子只用位移、缩放、透明度三种动画，**不加任何 Effect**：插件是半透明无边框窗口，上面的阴影/模糊类特效都是软件渲染，代价很高（实测卡片阴影约 9.6 ms/帧，无阴影约 3.2 ms/帧）。
  - 烟火画在窗口顶层一个 `IsHitTestVisible=false` 的 Canvas 上，既不参与命中测试也不参与测量，也不会被列表刷新（勾选后 0.26 秒的重建）清掉。

## 特别版（1.6 起）：圣旨皮肤

整套界面换成「经典古代圣旨」的样子，功能和数据完全不变：

- **配色与字体**：木牍（深棕）+ 明黄绢面 + 朱砂金线；标题和印章用华文新魏/隶书，正文用楷体。绢面是 8 px 平铺的极淡织纹 `DrawingBrush`（建好即冻结复用，几乎不占开销）。
- **主程序**：上下各一根鎏金卷轴轴杆，标题栏与侧栏换成木牍；侧栏小标题「奉天承运」，四个页面改叫「今日圣旨 / 本周奏章 / 已竟之事 / 钦此设置」，页眉右侧盖一枚「御览」朱印，正文用中间实两头淡的金线分隔。
- **插件**：顶部一根带两端金帽的轴杆 + 织锦外框 + 绢面，抬头写作「今 日 事 宜」。
- **左下角的小人**：清朝小皇帝正面半身卡通（`assets/minister.png`，306×495，调色板 PNG 约 44 KB），按 `宽 × 495/306` 摆成 78 px 宽，用 `HighQuality` 缩放；它独占页脚最后一行，**压不到任何文字**，鼠标悬停有提示。
- **小人会说话**：完成一件事时礼花照放，鼓励语改成小人的对话框（宣纸底 + 金褐描边 + 朱砂字 + 落款「—— 臣 恭 贺」，34 句恭贺口吻随机，如「臣恭喜圣上，又了却一桩」「贺喜圣上，此事已成」「臣恭贺圣上，心愿又了」）；当天的事全部办完时说「诸事皆了，臣恭贺圣上」。对话框从尾巴那侧弹出来（0.86 → 1 缩放 + 淡入，`FillBehavior.Stop`，不留下动画时钟），9 秒后自己回到待命的一句「臣在此候旨」。
- **右键菜单**：跟着换成木色皮肤（木牍底 + 鎏金描边），不再是深蓝。
- **插件最小高度**：拖动缩放的下限改成「页眉 + 周条 + 进度 + 页脚 + 小人都显示 + 留一块 110 px 的列表」，缩到最小也不会把小人或输入框压没（`WidgetWindow.MeasureCard`）。
- **图片内嵌**：小人以 `/resource` 打进两个 exe（`src/Core/Art.cs` 运行时从清单资源里读），交付目录里只有 exe，不需要外带图片文件。
- **插件周条（1.7）**：每格两行——上面周几、下面日期数字，今天描红加框、选中的那天填朱砂；底下的小圆点还是完成进度（绿 = 当天的事已全部办完，朱砂 = 办了还没办完）。鼠标停在格子上会显示「9月18日 周五 · 已竟 1 / 2 事」。
- **今日事明日毕（1.7）**：今日页的按钮（有待办时才出现）和插件右键菜单都能一键把这天没办完的事整体挪到第二天，主程序与插件都是「先换锚点、再动数据」——`Store` 改完会立刻通知重排，锚点没先换的话这一下刷的还是已经空了的那一天；插件点完会跟着跳到第二天，好让你看见事落在哪儿了。
- **「打开主程序」不再没反应（1.7 修）**：以前插件右键它经常像按了没动静——主程序多半缩在托盘里，窗口是 `Hide` 的，这时 `Process.MainWindowHandle` 就是 0，从头到尾找不到人；转头想重新拉起一个，又会被单实例互斥挡住，而那条路也是按句柄找窗口，于是彻底静默。现在两端挂一盏命名事件信号灯（`src/Core/AppSignal.cs`，`Local\TimePlanner.App.ShowMain`）：插件（以及被挡回来的第二个主程序实例）按一下灯，主程序守灯的后台线程收到就回 UI 线程 `Show()` + `Activate()`。主程序是老版本、灯没挂上时才退回原来的句柄查找与重启动。
- **主界面也有小人（1.7）**：常驻侧栏左下角，头顶一个对话框跟着今日进展报数（「尚余 3 事，臣这就办」/「诸事皆了，臣恭贺圣上」/「今日无事，臣候旨」），每次刷新这句话变了就弹一下；点他一下换一句随机贺辞，7 秒后自己回到进展那句（插件里那位也能点）。侧栏的「今日进度」卡片与「显示/隐藏桌面插件」按钮随之挪到侧栏最下面。他的话一律是臣子口吻的恭贺（落款「—— 臣 恭 贺」，34 句随机）。

## 主程序页面

- **今日**：完成率进度条、待完成/已完成分组、`◀ ▶` 切换日期、「今日事明日毕」（把这天没办完的整体挪到第二天）。
- **本周**：一周概览条（每天的任务数与完成比例，点击跳到当天）+ 按天分组安排，每天都有独立添加框；过去未完成的会标「已过期」。
- **已完成**：按完成日期归档的完成记录，勾选框可撤销完成，可一键清理 30 天前的记录。
- **设置**：插件层级/不透明度/插件大小与自适应还原/缩放/是否显示已完成、**全屏游戏与演示时自动隐藏插件**、主题色（6 种）、一周从周一开始、开机自动启动、数据目录与清理。

## 数据

- 数据文件：`%APPDATA%\TimePlanner\data.json`（UTF-8 JSON，可以直接查看/备份）。
- 首次运行会写入几条上手示例任务；删除该文件即可完全重置。
- 并发安全：写入使用命名互斥量 + 临时文件原子替换；两端用 `FileSystemWatcher` 监听变更（含防抖与自写抑制），不会互相覆盖。
- 写盘策略：勾选、改设置等操作先改内存并立即刷新界面，写盘在后台合并（约 0.2 秒内的多次操作只写一次），退出前会强制写一次，所以界面不会因为磁盘或杀毒软件扫描而卡住。

## 从源码构建

```powershell
cd TimePlanner
powershell -ExecutionPolicy Bypass -File build.ps1
```

构建产物在 `dist\`：`TimePlanner.exe`、`TimePlanner.Widget.exe`（约 130 KB / 107 KB，单文件、无外部依赖）。

**编译方式**：使用 Windows 自带 .NET Framework 4.8 的 `csc.exe`（语言级别 C# 5），不依赖 .NET SDK / Visual Studio，也不需要安装任何第三方包；`tools/MakeIcon.cs` 会先用 GDI+ 生成多尺寸 `assets/app.ico`。

**源码结构**：

```
src/Core    数据模型与存储（Store/FileSystemWatcher）、主题与配色、控件库（勾选框/任务行/进度条/开关/滑杆）、
            右键菜单皮肤（MenuSkin）、完成任务的礼花筒动画（Fireworks）、
            Win32 交互（窗口层级/位置/开机自启）、GDI+ 图标、离屏渲染
src/App     主程序：窗口外壳、今日/本周/已完成/设置四个页面、任务编辑弹窗、托盘、渲染彩排入口
src/Widget  桌面插件：卡片式任务面板、周条、拖拽改期、边缘拖拽缩放、位置与尺寸记忆、右键菜单
tools       图标生成器
```

**工程要点**

- 界面完全用 C# 代码构建（无 XAML、无资源字典），自绘圆角、阴影、动画与深色主题，可在任意机器上编译出同样的界面。
- 支持高 DPI（PerMonitorV2 清单）与多显示器工作区定位；插件定位基于 `SystemParameters.WorkArea`，不会被任务栏遮挡。
- 内置 `--render <目录>` 离屏渲染模式：把主程序四个页面、插件卡片、右键菜单皮肤渲染成 PNG，便于无人值守的界面回归检查（本仓库截图即由它生成）；渲染模式以只读方式打开数据文件，不会写回用户数据。
- 内置轻量诊断（`src/Core/Diagnostics.cs`）：界面线程卡顿、未捕获异常、全屏适配动作都会写进 `timeplanner.log`。
- 两个 exe 之间的「请你显形」走命名事件而不是窗口句柄（`src/Core/AppSignal.cs`）：窗口隐藏时 `Process.MainWindowHandle` 是 0，靠它叫不动人；信号灯在可见/隐藏两种状态下都能用。

## 发版（自动删掉上一版）

版本号只有一个来源：`TimePlanner/version.txt`（编译时由 `build.ps1` 写成 `AppVersion`，主程序「设置 → 关于」直接读它）。
一条命令出整套交付，并自动清掉旧版本：

```powershell
cd TimePlanner
powershell -ExecutionPolicy Bypass -File release.ps1                 # 用 version.txt 里的版本号
powershell -ExecutionPolicy Bypass -File release.ps1 -Version 1.5    # 换版本号（会写回 version.txt）
powershell -ExecutionPolicy Bypass -File release.ps1 -DryRun         # 只打印会删哪些，不动文件
```

`release.ps1` 依次做这几件事：

1. 停掉正在运行的主程序/插件（编译时 exe 被占用会报 CS0016），发完再把主程序拉回托盘。
2. 调 `build.ps1` 编译到 `dist/`。
3. 离屏渲染截图，铺满 `outputs/screenshots/`（主程序四页 + 两帧礼花 + 插件卡片 + 右键菜单 + 插件礼花）。
4. 铺出 `outputs/TimePlanner-<版本>/`，打 `TimePlanner-<版本>-app.zip` 与 `-source.zip`。
5. 刷新仓库根目录的 [`exe/`](../exe/)：把两个 exe + `使用说明.txt` + `启动时间规划.cmd` 拷过去，这就是提交进 git 的**免编译包**（GitHub 上直接下载就能跑，不用编译）。
6. **自动删除 `outputs/` 里其它版本的目录和压缩包**——只认「`outputs` 正下方、名字是 `TimePlanner-<数字版本>`」的目录和 `TimePlanner-<数字版本>-*.zip`，`screenshots/`、`README.md` 不碰；不确定时先跑 `-DryRun` 看一眼。

发版时记得手写的是「更新说明」：把 `dist/使用说明.txt` 里的「本版更新（旧版本）」改成「上一版（旧版本）」，再在上面补一段新的（标题里的版本号由脚本自动改）。

## 流畅度（1.2 起）

- 勾选任务、改设置等操作不再等待磁盘：主程序与插件在操作后立刻响应，写盘交给后台线程合并完成。
- 数据没变就不重建界面：另一端发出的同步通知如果内容没变化，会直接跳过重排重绘。
- 插件卡片阴影在拖拽缩放期间自动关闭（无边框半透明窗口的阴影是软件渲染，最费时间），松手后恢复。
- 主程序设置页不再每次刷新都枚举系统进程（进程检测结果缓存 2 秒）。
- 全屏游戏/演示时插件自动隐藏，退出全屏自动恢复。
- 程序不再因为一次界面异常弹出模态提示框（以前窗口不在前台时，弹框看起来就像整个程序卡死），改为写入日志。
- 礼花筒动画沿用同一套原则：不碰磁盘、不加特效、动画结束立刻摘除粒子（实测粒子约 0.9 秒飞到最远，1.14 秒后可视树里的粒子数回到 0）。
- 重建页面前先记住滚动位置、建好后再恢复（拖动改期或勾选完成之后页面不跳回顶部），每个页面各记各的（1.5 起，`MainWindow.RememberScroll/RestoreScroll`）。
- 拖动任务时贴住列表上下边缘会自动翻页（1.5 起，`Ui.DragScroller`）：拖拽期间鼠标被 `DoDragDrop` 的模态循环接管，滚轮和滚动条都不好使，这段是单独补的。这里的坑是 `ScrollToVerticalOffset` 要等下一趟布局才反映到 `VerticalOffset` 上——「到底了就停」如果跟刚设下去的值比，第一帧就会误判成到底然后停表（表现就是「贴到边缘只滚一下就停」），所以只能跟上一次 tick 的值比。

## 内存（1.5 起）

两个进程都是常驻的（主程序缩在托盘、插件摆在桌面上），所以空闲占用要尽量低：

- **托盘不再用 WinForms**：`System.Windows.Forms.NotifyIcon` 会为了一个图标把整套 WinForms 拉进进程（约 17 MB 程序集 + 一份 GDI+ 状态），现在直接调 `Shell_NotifyIcon`，消息窗口用一个不可见、不抢焦点的 `HwndSource`（`Core/NativeTray.cs`）。注册后会做一次自检并把结果写进日志，方便查「托盘图标怎么没了」。
- **插件走软件渲染**：`RenderOptions.ProcessRenderMode = SoftwareOnly`。插件只是一块静态小面板，软件渲染完全够用；实测省下约 20 MB 提交内存，并且不再加载 D3D 的着色器编译器（`D3DCOMPILER_47.dll`）。主程序保留硬件渲染——那是真正在交互、面积也大得多的窗口。
- **空闲回收工作集**：主程序只在窗口不可见（缩在托盘）时、插件只在鼠标不在它上面且没有动画时，调 `EmptyWorkingSet` 把工作集还给系统；要用到时系统按需调回来（都是文件页，不丢数据）。实测专用工作集：主程序 39.4 MB → 约 1 MB，插件 30.5 MB → 约 1 MB。拖拽期间不回收，避免拖着拖着发涩。

## 卡住了怎么查

- 日志文件：`%APPDATA%\TimePlanner\timeplanner.log`（自动记录界面线程被阻塞超过 1.2 秒的时刻、全屏隐藏/恢复时刻、以及未捕获的异常；超过 256 KB 会自动重建）。
- 出现卡顿时把该文件（连同发生时间）发出来即可定位。

## 已知边界

- 插件是独立进程：主程序退出后插件会继续运行（托盘选择「全部退出」可一起关闭）。
- 「贴在桌面」模式下按 Win+D（显示桌面）会连同插件一起最小化；需要一直可见时请切换为「始终置顶」。
- 只做了圣旨这一套皮肤（明黄绢面 + 木牍），没有做主题切换；不透明度与缩放可在设置里调整，插件尺寸也可以用鼠标直接拖出来。
