# 时间规划 TimePlanner

Windows 桌面上的时间规划小工具：一个**主程序**用来规划今日与本周的计划，一个**桌面挂件**常驻桌面显示任务、勾选完成。

原生 WPF（.NET Framework 4.8 / C# 5），**零第三方依赖**，界面全部由 C# 代码绘制（无 XAML、无资源字典），只用 Windows 自带的 `csc.exe` 就能编译。

## 不想编译？直接下 exe

两条路，都不用编译：

- **发行版（Releases）**：[`sp1 特别版`](https://github.com/evident150/timeplanner/releases/latest) 里直接下 `TimePlanner-sp1-special-app.zip`，解压双击就能用；经典版那条线最新是 [`1.5.2 经典版`](https://github.com/evident150/timeplanner/releases/tag/classic/v1.5.2)（带 `TimePlanner-1.5.2-classic.zip`），起点是 [`1.5 经典版`](https://github.com/evident150/timeplanner/releases/tag/v1.5)；历史上每一版都在[发行版列表](https://github.com/evident150/timeplanner/releases)里。特别版这条线的编号是 `sp1`、`sp2` …（`sp1` 就是原来的 1.8），交付物叫 `TimePlanner-sp<n>-special-app.zip`
- **仓库里的 [`exe/`](exe/) 目录**：**当前版本**的免编译包（每次发版由 `release.ps1` 自动刷新），点进去单独下两个 exe 也行

`exe/` 里是这些：

- `TimePlanner.exe` — 主程序（规划今日与本周）
- `TimePlanner.Widget.exe` — 桌面挂件
- `使用说明.txt` — 上手说明
- `启动时间规划.cmd` — 双击启动

两个 exe 必须放在同一个文件夹里。想要源码自己编，见下面的「从源码构建」。

## 特性

- **主程序五个页面**：今日（完成率进度条 + 待办/已完成分组 + 日期切换 + 今日事明日毕）、本周（一周概览条 + 按天分组，任务可按住拖到别的日期，拖到列表上/下边缘会自动翻页）、项目档案（大项目 / 分段 / 小项目，见下条）、已完成（按完成日期归档、可撤销、可清理）、设置（插件层级/透明度/大小、主题色、全屏自动隐藏、开机自启）。
- **桌面挂件**：卡片式任务面板，点圆圈勾选完成、拖标题栏移动、八向边缘拖拽缩放、周条跳到指定日期、木色自绘右键菜单（贴在桌面 / 始终置顶 / 普通窗口）。
- **完成任务的礼花筒**：勾选框处举起一个小纸筒，一束彩纸扇形喷出，旁边的小人同时弹一句贺辞；当天任务全部完成再补一筒更大的。只用位移/旋转/透明度动画，放完立刻回收，不常驻占 CPU。
- **项目档案（sp1 起）**：计划能再分一层。立一个大项目（「毕业设计」），往里加小项目，或者用「分段」把项目分期（「开题阶段」→「定稿阶段」）；**最低一级的小项目本身就是一条任务**，所以它和普通任务一起出现在今日、本周和桌面挂件里，勾选、拖动改期、顺延、放礼花全都一样，行上只多一枚归属小标签（毕业设计 / 开题阶段）。大项目和分段那行显示「已竟 x / y」的进度（= 底下所有小项目 + 大项目自己分的份），行内可以加下級、改名、上下挪、删除（点一下直接删，连子孙和它们的事项一起删）。不想一条条写小项目时，大项目或分段那一行都有 `⊖ n ⊕` 直接分出几份，再拖那条横条记「几份之几」（拖到最后一格 = 整段办完）；容器行最前面那枚圆勾跟任务行上的勾选框是**同一个控件** —— 点一下整段办完（底下的小项目全部勾上、份数置满、名字跟任务标题一样划掉）再点撤销，照样放一筒礼花；桌面挂件上，分了份的大项目 / 分段也各占一行，只写「x/n」，点一下那枚勾就办完 1 份（办满最后一份才放礼花）。
- **今日事明日毕**：一键把这天没办完的事整体挪到第二天，主程序今日页有按钮，插件右键菜单里也有一项。
- **旧账不再隐形**：今天空着、前几天却还压着没办完的事时，今日页顶部和插件顶上都会写一句「此前尚余 N 事未竟」，旁边「全部挪到今天」一按就顺延过去，不会再对着空页面以为数据丢了。
- **特别版皮肤（1.6 起）**：整套界面是「经典古代圣旨」的样子——木牍 + 明黄绢面 + 朱砂金线，主程序上下各一根鎏金卷轴轴杆；插件左下角和主程序侧栏各有一位清朝大臣半身卡通小人，你办成一件事他就弹对话框贺一句（34 句恭贺口吻随机）。
- **输入语法**：`写完周报 !!` 紧急、`!` 重要、`#工作` 打标签。
- **不卡**：勾选、改设置立刻响应，写盘交给后台合并；全屏游戏/演示时挂件自动隐藏；内置诊断日志记录界面卡顿。
- **不跳回顶部**：拖动改期、勾选完成后列表停在你原来的位置，每个页面各记各的。
- **省内存**：托盘图标直接调 Windows 系统接口（不把 WinForms 拉进进程）、挂件走软件渲染，空闲时两个进程的工作集都会降回 1 MB 上下（详见 [TimePlanner/README.md](TimePlanner/README.md) 的「内存」一节）。
- **版本隔离**：单实例、进程间信号灯、挂件进程、开机自启条目都按「版别 + 安装目录」各算各的，
  所以特别版和经典版可以同时装着、同时开着，互不打扰；数据仍然共用一份。同一目录重复点还是只开一个。
- **一份更新日志**：两条产品线的改动都记在 [CHANGELOG.md](CHANGELOG.md)，标 `[内核]` 的条目
  经典版照单同步就能跟上（`sync-classic.ps1`）。

## 使用

1. 双击 `TimePlanner.exe`（会同时启动桌面挂件）。
2. 点任务左侧圆圈 = 完成；底部输入框回车 = 新增任务。
3. 主程序点 ✕ 只是隐藏到托盘，托盘右键可退出。

数据放在 `%APPDATA%\TimePlanner\data.json`，主程序与挂件共用；删掉它就是完全重置。每次覆盖前会自动留一份 `data.json.bak`，主文件写坏时下次启动自动从它恢复。

## 版本

两条产品线，各自一个版本序列，**标签也分开**（互不覆盖、互不比大小）：

| 线 | 界面 | 版本序列 | 标签 | 交付物 |
| --- | --- | --- | --- | --- |
| **特别版** | 圣旨皮肤 + 小人（1.6 起） | 1.6 → 1.7 → sp1 → sp2 … | `special/sp<n>` | `TimePlanner-sp<n>-special` |
| **经典版** | 1.5 那套深色卡片 | 1.5 → 1.5.1 → 1.5.2 … | `classic/v<版本>` | `TimePlanner-<版本>-classic` |

| 标签 | 版本 | 说明 |
| --- | --- | --- |
| `special/sp1` | 特别版 sp1（当前） | 项目档案（大项目 / 分段 / 小项目）、大项目与分段按份记进度、插件上按 1 份一勾；写盘失败会写日志 + 侧栏亮红字、每次写盘留快照 |
| `special/v1.7` | 特别版 1.7 | 圣旨皮肤 + 主程序与插件都有小人；新增「今日事明日毕」，修好插件右键「打开主程序」 |
| `special/v1.6` | 特别版 1.6 | 整套界面换成圣旨皮肤，插件左下角小人开口说话 |
| `classic/v1.5.2` | 经典版 1.5.2（当前） | 写盘失败会写日志 + 侧栏亮红字、每次写盘留快照（改动不再无声无息丢）；项目档案（大项目 / 分段 / 小项目）、大项目按份记进度、插件上按 1 份一勾 |
| `classic/v1.5` | 经典版 1.5（旧名 `v1.5`） | 经典版序列的起点：深色界面，没有圣旨皮肤和小人 |

每个版本在 [发行版](https://github.com/evident150/timeplanner/releases) 里都有一条：`sp1 特别版` 带免编译附件（`-app.zip` / `-source.zip`，外加两个单独的 exe），
`1.5.2 经典版` 带 `TimePlanner-1.5.2-classic.zip`、`1.5 经典版` 带 `TimePlanner-1.5-classic.zip`（都解压即用），`1.6` 只带源码。深色卡片那条线就下最新的 `1.5.2`。
按标签下载也能拿到源码快照（GitHub 上 `Code → Download ZIP` 只给主线最新版）。
标签已经改名：`v1.6` / `v1.7` → `special/v1.6`、`special/v1.7`（远端旧名字已删，两条老发行版也跟着改指过去了）；`v1.5` 保持不变（外面还有链接指着它）。
特别版这条线：1.6、1.7 保持原名，之后改用 `sp<n>` 编号（`special/sp1` 就是原来的 1.8，现在是 `sp2` …）；当前最新是 `sp1`。
这台电脑上的改动**先在经典版生效**（改完就同步 + 编译），特别版由作者统一点名才更新。

## 从源码构建

```powershell
cd TimePlanner
powershell -ExecutionPolicy Bypass -File build.ps1      # 编译到 dist\
powershell -ExecutionPolicy Bypass -File release.ps1    # 一条命令出整套交付（并自动删掉上一版）
```

版本号只有一个来源：特别版的 `TimePlanner/version.txt`。
经典版是另一条线，源码树在 `work/classic`（`git worktree`，基于标签 `classic/v1.5`），
一条命令就能把主线的内核和界面改动同步过去并编译（哪些算内核，见 [CHANGELOG.md](CHANGELOG.md)）：

```powershell
powershell -ExecutionPolicy Bypass -File sync-classic.ps1                         # 同步 + 编译
powershell -ExecutionPolicy Bypass -File sync-classic.ps1 -Version 1.5.1 -Release  # 顺便铺 outputs\ 并打包
```

详细的工程说明（源码结构、性能取舍、发版流程、两条线怎么同步）见 [TimePlanner/README.md](TimePlanner/README.md)。
